# SpotipyFree documentation

SpotipyFree is a Python package with a Spotipy-style interface for Spotify
catalog information, account data, and playback controls. This documentation
shows how to install the package, use its features, and connect them to Python
applications.

## At a glance

- **Package:** `spotipyFree` on PyPI
- **Python:** 3.9+
- **Import:** `from spotipyfree import Spotify`
- **Features:** catalog search and lookups, account data, playback controls,
  and a local HTTP interface
- **Authentication:** not required for some catalog lookups; required for
  account and playback features
