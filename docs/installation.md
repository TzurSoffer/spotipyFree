# Installation

## Requirements

- Python 3.9 or newer
- Internet access

## Install from PyPI

```bash
python -m pip install spotipyFree
```

## Optional Flask server

Flask is not declared as a SpotipyFree dependency. Install it separately only
if you need the optional HTTP server:

```bash
python -m pip install Flask
```

See [Using the local web API](web-api.md) for setup and security requirements.
